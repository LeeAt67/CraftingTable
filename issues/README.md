# Issues

CraftingTable 的缺陷索引。**维护规范见 [AGENTS.md](./AGENTS.md)**，登记与修复前必读。

- 这里有 issue 时，说明该模块存在**已确认**的缺陷，不是待评估的猜测。
- 状态为 `待修复` 或 `修复中` 的条目，优先级高于新功能开发。
- 只登记**页面可复现**或**确定性测试可复现**的问题。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| `待修复` | 已确认，尚未动手 |
| `修复中` | 有进行中的分支或提交 |
| `已修复待验证` | 代码已改，回归待跑 |
| `已关闭` | 回归验证通过 |
| `不复现` | 尝试复现失败，保留记录 |
